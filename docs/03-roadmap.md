> 版本：v0.2（2026-11-11）· 初稿：claude · 本次调整：codex · 原则：每期结束都有可验证的使用闭环

## 当前状态与下一轮执行顺序

2026-11-12 后续更新：R0 修复见 [构建记录](06-build-progress-2026-11-11.md)；R1 已有材料导入、OCR/校正、旧 DOC/PPT 转换、规范来源、人工语义条目及可审核 AI 建议，交付与剩余边界见下文。R2 人工校准课堂联动已交付，包含分屏、PDF 原页、课前起点、历史来源、回链及课堂恢复，见 [R2 记录](08-classroom-material-link.md)。真实课堂/硬件验收仍待进行。R3 已有知识证据与逐条审核的 AI 知识候选；保留章节、图文/公式、完整交换格式及真实模型质量评估等未完成项，不把文字导入等同于完整教材理解。

初始体检基线为 M0 主要界面与 M1a 管线；当时发现的对话显示、数据迁移与流式保存问题详见 [体检报告](05-health-check-2026-11-11.md)，修复状态以上述后续记录为准。知识页已追加概念别名与自动关联基础，AI 知识抽取及图谱仍待实现；习题库和复习页仍为占位，项目、日程、备忘尚未实现。

以下 R0–R6 是本次重新安排的**执行顺序**，M0–M5 保留原功能分组，避免把旧阶段名误当作完成标志。教材导入从原 M3 提前，支撑用户优先提出的课堂联动；自动分类与排程在基础实体可用后接入。细节、数据边界与场景验收见 [扩展规格](04-product-expansion.md)。

| 顺序 | 范围与依赖 | 最小交付与验收 |
|------|------------|----------------|
| R0 可靠性与协作 | 开始新增业务前；对应体检 H01–H11 | 模型目录/压缩包排除 Git；对话首条响应可见；中止保留内容；迁移不覆盖已有库且失败可恢复；课堂结束保存尾句；针对确认缺陷补回归检查；完善其余可靠性问题 |
| R1 材料基础（提前 M3） | R0；稳定来源位置是后续前提 | 课件/讲义/教材导入，先验收 PDF、DOCX、PPTX，再验收 DOC/PPT 转换与扫描 OCR；按学科条目化、原件与版本保留、搜索回原位、导入进度/取消/重试；切块不乱序且携带稳定位置 |
| R2 教材课堂联动 v1 | R1 + M1a | 左半屏材料右半屏记录；课前开始点；课中手动校准、切换材料；段落与教材双向定位；注入附近教材上下文且保留原转写；重启后引用仍有效 |
| R3 知识引用与应用基础（M2 核心） | R1–R2 | 抽取/合并知识点、保留证据、笔记与材料定位关联、跨学科检索；先形成可用的列表与引用闭环，再增强图谱、预回答缓存和习题关联 |
| R4 项目管理 | R3；先定义统一任务模型 | 项目要求、计划书、版本化文档、里程碑、当前进度、阻塞与截止时间；任务引用知识点并展示学习/应用路径；至少一个跨学科项目完成双向回链验收 |
| R5 日程与可靠提醒（整合 M4） | R4 的任务模型；手动任务可先交付 | 统一项目/手动/作业/复习任务；区分截止时间与时间块；自动安排、依赖/冲突检查、锁定与撤销；通知持久化、去重、重启/休眠恢复；明确应用退出后的运行条件 |
| R6 备忘自动分流与课堂对齐增强 | 自动分流依赖 R3–R5，自动对齐依赖 R1–R2；两部分可分别交付 | 备忘先保存原文，再自动分类至已有知识库/日程，支持混合条目、去重、撤销、待整理箱与离线补处理；课堂自动估计教材位置并显示置信度，人工校准优先 |

备忘的“快速保存原文”入口可在 R4/R5 期间提前交付，但不把自动归档提前标为完成。图谱美化、外部同步、复杂数学工具和桌面小组件按原阶段保留，优先保证上述闭环。每批功能随附相应 migration、IPC、界面和有实际意义的验收，不先创建一批空页面宣称交付。

## R1 后续：统一学习文档（2026-11-11 补充）

格式草案、JSON Schema 与演示样本见 [统一学习文档](09-learning-document-format.md)。建设顺序：来源序列/稳定语义条目与人工修正 → 统一排版和类型检索 → AI 拆分/归属与审核 → 图像、公式及旧格式适配 → 知识点及项目复用；OCR 因真实教材为扫描件而提前。规范来源与人工整理首批已接入，具体边界见下文；不将现有 900 字检索块当作定义/定理等语义边界。

自动关联补充已实现：复用已有知识点实体，确认别名在现有材料块、笔记阅读及课堂文字中自动匹配，提供卡片、歧义候选和反向查找，见 [关联记录](10-concept-alias-links.md)。这是语义格式的概念层基础，不代表完整语义条目导入已完成。真实教材验收确认 PDF 为 353 页扫描件，优先补 OCR 样例与质量验证；转换后的 53 页课件及实验讲义已验证文字导入和概念回链，应用内旧格式自动转换仍待接入。

OCR 首批现已交付：PDF 指定 1–20 页本地识别、按原页校正、派生版本保留、按页检索与概念回链、取消/重试/重启恢复，见 [OCR 记录](11-local-ocr.md)。真实教材正文第 26–27 个 PDF 页面通过样例验证；目录页质量不足，尚不代表整本教材验收。下一批回到统一格式的稳定来源单元、人工语义类型/边界、统一排版与类型检索，再接入 AI 候选拆分及审核。公式/配图、复杂版面和旧格式自动转换仍未完成。

学习文档首批现已交付：规范来源、人工类型与标题、同页拆分/跨页合并、证明/解答归属、按类型排版和搜索、不可变修订、历史查看及陈旧修改拒绝，见 [语义条目记录](12-semantic-entries.md)。全部来源覆盖校验拒绝漏段/重复；初版是待整理叙述，不代表 AI 分类。

AI 候选拆分与审核首批已接通，见 [AI 整理记录](13-ai-semantic-review.md)：用户选择模型和待整理范围，模型返回程序片段编号、类型、标题及证明/解答归属，校验后仅保存候选；人工采纳才生成新修订。人工确认条目受保护，旧候选不能覆盖期间的编辑。取消、坏输出、请求失败和实际应用重启已通过本地模拟模型验收，真实模型语义质量尚待评估。

旧 DOC/PPT 输入适配已接通，见 [转换记录](14-legacy-office-conversion.md)：选择本地 LibreOffice，后台转换成只读 DOCX/PPTX，保留原件、转换产物、散列及引擎版本，接入检索与学习文档。真实热力学课件 53 页 / 436 个来源和十字轴实验讲义 80 个来源通过导入与跨进程重启验证。复杂版式/公式保真尚待对照，章节结构、配图/公式与完整交换格式仍未接入；后续进入 R3，补充知识点与具体语义条目之间的证据引用，再扩展项目应用。

R3 知识证据首批已交付，见 [证据记录](15-knowledge-evidence.md)：语义条目与已保存笔记字段显式引用到知识点、原子新建知识点并引用、固定修订原位导航、笔记变化/删除后保留快照、学科筛选与来源反向查找。自动名称提及与人工证据分开，旧证据不随新修订改写。AI 知识候选第二批已接通，见 [候选记录](16-knowledge-suggestions.md)：仅发送所选来源，校验名称/别名/摘录，逐条编辑并确认后新建知识点或增加证据，不自动覆盖已有知识。实体合并、依赖图谱和项目系统尚未实现。

验收需覆盖同页多类型、跨页证明、图文关联、定理/命题区分、例题/解答关联、原件对照、AI 漏段拒绝、人工修改保护和旧课堂链接保留。先短讲义后整本书；复杂解析器先用中文数学/力学样例比较再引入。

2026-11-11 用户补充的后续交付：**内部格式完善后，课堂自动整理笔记也使用同一格式，并可将任意内部学习文档导出 PDF**。课堂保留原始转写、时间与教材锚点，复用来源/条目/关系/修订；导出固定修订，保留样式、公式及来源，验收中文字体、可搜索文字和跨页不裁切。详情见 [格式补充](09-learning-document-format.md)。尚未实现，不以现有段落分色替代统一格式。证据引用批次完成后曾按要求暂停，2026-11-12 用户恢复工作；先完成知识候选小批次，再继续完善内部格式及其课堂/PDF 复用。

## M1 — 课堂模式（转写流水线）

**目标**：真实课堂可用的实时转写 + 段落整理。**本地优先**（用户确认）：转写默认走本地 Provider，完全离线可用。

**M1a 已实现（2026-11-10，真实课堂验收待完成）**：
- 课堂页：setup（挂学科/活动、ASR 就绪检查）→ live（转写流+partial 实时行、段落分色、双视图、段落级标注、手动转写输入——无引擎时降级手动模式，管线一致）
- 本地 ASR：sherpa-onnx-node（optionalDependencies，v2.0.1）+ 流式 zipformer；端点检测自动断句；热词表；麦克风采集（渲染进程 16k PCM → IPC 喂数）
- AI 整理管线：final 落段 → 自动 LLM 整理（分类 seg_type + 纠错 + LaTeX 规整，JSON 容错解析），失败回退原文（ADR-0 降级）
- 语音引擎设置卡（模型目录/热词/安装状态）+ 数据与存储卡（自定义存储位置、迁移、恢复默认）

**M1b 待办**：

- 2-pass 精转修正（流式 partial + VAD 离线 final 替换，飞书妙记式，参考 cueflow #2150）
