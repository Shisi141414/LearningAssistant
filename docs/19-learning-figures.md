# 学习文档配图与附件来源

> 2026-11-12 · 设计与报告：codex · Office 嵌入配图首批交付

## 复用与取舍

复查 [OfficeParser 附件接口](https://github.com/harshankur/officeParser/blob/master/src/types.ts)、[解析配置](https://officeparser.harshankur.com/) 和 [PDF.js 图像渲染讨论](https://github.com/mozilla/pdf.js/issues/6419)。直接复用现有 OfficeParser 的 `extractAttachments`、图片节点及幻灯片元数据；新增零依赖 [image-size](https://github.com/image-size/image-size) 2.1.0 先检查文件头尺寸，再用已有 `@napi-rs/canvas` 解码验证，避免先解码过大图片；不另写 DOCX/PPTX ZIP/关系解析器，也不把 PDF 的整页截图自动认作正文配图。image-size 的 GitHub 已归档迁移至 Codeberg，本批锁定发布包并只接受 PNG/JPEG，不依赖未发布主干。

首批支持 DOCX/PPTX 及已有 DOC/PPT 转换产物中的嵌入 PNG/JPEG。配图提取是显式后台操作，无网络、无 OCR 或视觉模型。SVG/EMF、图表、组合图形等未支持内容保留原件并提示；PDF 仍可对照原页，页内裁图与版面关联另批建设。

## 数据与恢复

新增迁移 14：图片附件属于学习文档，保存 SHA-256、媒体类型、像素尺寸、托管相对路径及原始图片节点位置；提取完成记录保存引擎与警告。图片按提取出现位置保留，重复图片出现多次可分别引用；Word 使用结构路径，PPT 使用幻灯片及结构路径，不虚构页码或精确图文对应。解析及解码在工作线程完成，每图最多 8 MiB / 1600 万像素，每篇最多 100 图 / 50 MiB。

先完整写入本批独立目录，再原子登记数据库；失败或取消不发布半份附件。退出中断不自动启动提取，可重新操作；未被数据库引用的中断副本不参与阅读。已有文字、章节、公式、课堂位置和知识证据不重建。托管附件置于 `materials`，复用已有数据迁移复制边界。

条目增加 `figures`（附件 ID 与用户图注），显式选择配图后生成新修订，图片显示于该条正文之后。正文原始来源不变；图片归属只代表人工整理，不代表模型理解。附件不能跨文档引用，旧修订继续指向原附件；拆分/合并与 AI 替换不能丢失人工配图，首批提示先移除配图。改标题、章节、证明关联保持配图。

本地图片协议只接受附件 ID，由主进程查库、验证路径和散列后返回 PNG/JPEG；渲染端不接收绝对文件路径，也不能从教材中加载任意外链。原件与已登记的附件不可覆盖。

## 界面

保持宋体正文、黑体标题；背景 #f7f7f5、正文 #1f2328、辅助 #6b7280、边线 #e5e5e0、操作 #4f46e5。在学习文档工具栏下折叠“文档配图”显示提取入口、取消、结果/警告与按来源排列的缩略图；编辑条目时下拉选择当前文档配图、填写图注、预览并保存。阅读图宽不超过正文列，图注与人工整理标记在图下，失败显示对照原件提示。正文左对齐、图在正文列居中，不新增独立弹窗或装饰性卡片。

```
文档配图 [提取 / 取消]  来源与缩略图
正文条目
  文字 / 公式
  配图 + 人工图注 + 原图位置
  整理条目：选择配图 / 图注 / 保存
```

验证升级与事务失败恢复、解析器真实嵌入图、同图多次出现/幻灯片位置、损坏或超限附件、取消不发布、跨文档拒绝、人工修改保护、协议散列/路径、只读历史、来源与证据不变、实际图片渲染、1024 宽和跨进程重启。短样本先验收，再用用户提供的真实教材核对提取边界。

## 使用与验证

材料库 → 学习文档 → 展开“文档配图” → 提取。再打开某条的“整理条目”，选择图片、填写图注、预览并保存；支持同一图片在不同条目引用、同一条图片图注修改或移除。移除仅解除当前条目的引用，附件及历史图注仍保留。配图图注参与本篇搜索；知识证据及 AI 知识候选目前仍取原始文字，不自动识别图中知识。

迁移 14 从 v13 升级，并验证事务中途失败回滚及旧来源/修订/证据保留。新增七项逻辑回归，覆盖解析位置、重复图片、损坏/超限、取消和落盘失败清理、跨文档拒绝、协议路径/散列检查、人工配图保护与数据库重开。`npm test` 通过 71 项逻辑回归及实际 Electron 首次/重启检查；`npm run typecheck` 与构建通过。

实际应用验收使用含重复嵌入图的 DOCX、物理文件顺序与播放顺序不同的 PPTX、纯图片 DOCX，覆盖提取/取消、真实图片载入、表单保存/编辑/移除、历史只读、图注搜索、跨进程重启及 1024 宽截图。验收发现并修复图片协议未加入页面图片白名单、纯图片 Word 在关闭附件提取时没有图片节点两处问题。普通文字文档继续使用既有来源提取配置，不重建旧来源。

真实材料使用隔离数据库和已有本地 LibreOffice：热力学旧 PPT 转换后保留 53 页 / 436 个来源，提取 27 个受支持图片引用、1 处未支持或没有 PNG/JPEG 的图片节点；十字轴实验旧 DOC 保留 80 个来源，提取 10 个受支持图片引用、60 处未支持或没有 PNG/JPEG 的图片节点。逐图通过实际页面协议读取，提取前后当前修订与来源不变；原件散列未变，关闭应用、清除转换器设置后重启，附件散列/位置、来源及转换记录仍保留。重复出现的同图按各自位置计数，不把张数当成独立图片数。未支持节点保留警告，尚未对这些节点逐一判定是否为公式、矢量图或缺失附件，因此不能宣称讲义配图已完整提取。

本批保留以下限制：不自动判断图片对应哪段正文，不转换 SVG/EMF/组合图形/图表，不处理 PDF 页内裁图，不以提取张数证明教材图文完整。纯图片 Office 文档允许保留空正文的来源占位；它不代表已识别图中文字，需人工对照原件。

后续 PDF 人工选区配图已在独立批次接通，具体坐标、保存、原页回链及扫描教材验收见 [PDF 选区记录](20-pdf-figure-crops.md)。上述 Office 自动提取边界不变。
