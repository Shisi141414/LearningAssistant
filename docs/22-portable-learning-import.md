# 学习文档包预览与导入

> 2026-11-12 · 设计与报告：codex · 导入入口及隔离数据验收

## 复用选择

查阅 [Joplin 导入器的编号映射与引用重连](https://github.com/laurent22/joplin/blob/dev/packages/lib/services/interop/InteropService_Importer_Raw.ts)、[better-sqlite3 事务与嵌套事务](https://github.com/WiseLibs/better-sqlite3/blob/master/docs/api.md) 和 [SQLite 原子提交机制](https://www.sqlite.org/atomiccommit.html)。参考 Joplin 的编号重建思路，没有移植其应用代码；其笔记/文件夹模型不能直接处理本项目的规范来源、语义范围、知识证据和课堂链接。直接复用已有 ZIP/Schema 编解码器、SQLite 事务、规范条目校验及文字切块器，仅实现本项目实体之间的对应关系；不新增压缩、数据库或转换依赖。

## 用户流程

材料库新增“导入学习文档包”：选择 `.ladoc` 后，后台检查全部字段、来源覆盖、关系、图片和文件散列，预览标题、原件格式、原学科及各项数量。预览前后均不创建材料或概念；选择目标学科，可决定是否携带概念与知识证据，再确认保存。取消预览或检查中取消不改变现有材料。离开材料库会取消本页面的预览；票据有效期 10 分钟，确认后失效。

导入为独立材料和固定修订，原件、旧 Office 转换产物、规范来源、章节、公式、配图及坐标、OCR 原文/校正、已采纳 AI 归属信息保留。自动生成检索块，不以重叠检索块反向拼正文。来源、条目、章节父级、关系端点、配图和证据重新映射编号；数据库保留包 SHA、原文档/版本/修订标识及编号映射。旧材料、原有课堂位置与知识证据不修改。

同一包再次导入同一学科，打开已有副本的当前修订，保留导入后手动修改；不会按新选项补入概念或重复创建。导入另一学科可以建立新副本。删除学科仍保留材料、修订及导入来源，解除其学科归属。

## 概念与证据

同学科或通用概念的规范名称、释义和规范化别名集合完全一致时可复用；仅同名不足以认定为同一知识。同名不同内容创建独立概念，保留现有自动关联的歧义提示，不覆盖原概念。包内原本不同的概念编号不自动合并为同一编号，防止证据角色/说明丢失。结果显示新建、复用和冲突数量。

只导入所选修订中的证据，重新连接到本地条目和固定修订，原文散列保持不变。不携带概念时也不导入其证据，条目内容和图片照常保存。现有词典 2000 个概念 / 十万字符、每概念 100 条证据限制继续生效；超限整批回滚，不能默默截断。

## 原子登记与恢复

新增迁移 15，只追加 `learning_package_imports`，不改既有迁移。预览附件暂存在本批独占临时目录，原包路径和附件绝对路径不交给渲染进程；确认只接收一次性票据、学科 ID 和携带概念选项。

文件和数据库不能组成同一个 SQLite 事务：先登记待处理日志，创建独占材料目录，逐个复制并在后台复核实际字节/图片，文件同步落盘后，再用一个数据库事务登记材料、来源、修订、检索块、概念、证据及完成记录。失败/取消清理本批已知文件，回滚所有业务记录。若进程被中断，启动时根据未完成日志清理，不发布半份材料；已完成记录及其附件保留。

恢复会跳过仍存活进程的记录，拒绝越界/链接目录；只清理登记文件，不递归删除，未知文件保留并记录错误，等待检查。极小的“创建空目录但尚未登记”窗口可能留下空目录；崩溃前未确认的系统临时预览也可能残留。本批验收应用进程中断，不声明已做物理断电测试。数据迁移须先结束预览/导入，应用退出停止后台任务。

## 验证与边界

新增 9 组回归覆盖迁移 14→15 和失败回滚、旧来源/图片/证据保留、UTF-16/章节/公式/配图/证明映射、OCR 原文校正、精确概念复用与冲突、重复导入保留人工编辑、跨学科与学科删除、校验/事务/取消三种回滚、预览后字节变化、存活进程/只读附件/未知文件恢复、严格 IPC 和伪造票据拒绝、合成 DOC/PPT 的原件/转换产物独立保留及证据容量超限回滚。

99 项逻辑回归、类型检查及构建通过。实际 Electron 验证系统选框取消、预览不写库、取消检查/预览、确认后读取图片、一次性票据、重复及跨学科导入，检查 1024 宽布局并截图。另启动全新进程和空数据目录，从前一目录导出的 DOCX 与 PDF 包导入，逐项还原编号比较来源和语义状态，核对原件 SHA、配图显示、知识证据及 PDF 选区坐标；模拟复制中断遗留半成品后，结束原进程并真实重启，检查启动清理、已导入副本及原有课堂引用。

当前仍只交换一个固定修订，不携带全部编辑历史、未采纳候选、录音或课堂笔记。真实大型教材及旧 DOC/PPT 转换产物的跨目录导入继续验收；内部格式用于课堂整理、内部文档导出 PDF 仍按路线图推进，不由本批替代。
