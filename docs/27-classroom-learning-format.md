# 课堂实时统一文档（2026-11-12）

报告：codex

## 本批结果

课堂右侧默认显示与笔记页共用的统一文档，保留左侧教材、录音/转写会话、手动补充记录和原有整理/原文视图。类型排版、公式、概念关联、章节检索、人工结构编辑、固定修订和 PDF 导出复用现有阅读器；阅读与导出选项默认收起，让正文优先显示。

点击条目来源时，在左侧浏览对应教材，或在右侧切换并定位当前原文段落，不跳离课堂。浏览教材不改变讲授位置，必须明确点击“校准到这里”才影响后续记录。原文已删除时提示仍可核对来源快照。

## 开源调研与选择

构建前查看了 [TanStack Query](https://github.com/TanStack/query)、其 [失效与后台更新方案](https://github.com/TanStack/query/blob/main/docs/framework/react/guides/query-invalidation.md)、[社区关于后台更新与表单数据的讨论](https://github.com/TanStack/query/discussions/8755)，以及已使用的 [Zustand](https://github.com/pmndrs/zustand)。异步清理和最新回调依据 React 的 [useEffect](https://react.dev/reference/react/useEffect) 与 [useEffectEvent](https://react.dev/reference/react/useEffectEvent) 说明。

选择直接复用当前阅读器、React 和主进程的修订协调逻辑。此处只有应用内部通知与一个文档读取入口，无需为此增加完整请求缓存依赖；小型 Hook 仅处理读取队列和暂停，不另建一份笔记真相。未复制外部项目代码，也未增加依赖或数据库迁移。

## 更新与保护边界

- 只在已经保存的段落列表或整理结果变化后通知文档更新。识别中的临时文字独立显示，不触发全文读取；稳定属性和 React memo 避免因此反复渲染阅读器。
- 首次变化后约 250 毫秒合并读取，连续事件不会无限延后定时器；每次只进行一个后台读取，期间的新变化排队，完成后再取最新结果。
- 编辑、来源同步预览、选定历史修订、导出、关闭跟随或切换至其他课堂视图时暂停后台应用结果。原始转写继续落库，恢复后读取新内容。
- 暂停或离开后，已发出的旧读取结果会被忽略。明确选中的固定修订始终只读；点击“读取最新笔记”才返回可编辑的最新状态。
- 人工结构仍由已有来源同步预览及修订检查保护，陈旧确认不能覆盖新来源。阅读器在课堂标签间保留，不因切换原文视图销毁未保存草稿。
- 默认不自动滚动打断阅读；“查看最后条目”明确跳转。新内容不会重置已有筛选条件。

可以把这一设计理解为“通知失效，按需重读”：课堂保存负责可靠写入，阅读器负责显示某个修订。两者之间用小队列衔接，避免把不断变化的转写直接当作编辑器草稿。

## 验证

新增 `scripts/test-classroom-learning.cjs`，使用隐藏的真实 Electron 窗口、预加载接口、主进程和 SQLite，不以静态截图代替交互验证。测试依次生成 16 个条目，覆盖：

- 手动输入、已保存的识别结果和真实整理管线写回；非本课堂事件与临时识别不引发全文更新。
- 关闭/恢复跟随、未保存草稿跨视图保留、来源变化预览和陈旧确认拒绝。
- 连续事件串行合并、读取期间追加变化后追上最新内容、迟到响应不覆盖历史修订。
- 单次读取失败保留当前文档，后续新事件恢复；保存框打开期间暂停阅读更新，取消后追上最新来源。
- 点击教材/原文来源不结束课堂，浏览不改变校准位置，结束课堂才关闭会话。
- 1024 × 768 窗口无横向溢出，正文和草稿实际可见；截图已人工查看。

`npm run test:classroom` 可单独运行；`npm test` 已加入本项。原材料课堂测试及真实重启后的追加记录断言改为验证默认统一条目，来源位置和校准断言不变，原笔记结构和 PDF 检查保留。完整 `npm test`、`npm run typecheck` 和构建均通过：115 项逻辑检查、材料/文档包/笔记的真实重启检查、120 条笔记的 41 页 PDF 检查及本批课堂测试通过；文档链接和差异检查通过。

## 局限与后续

本批验证使用合成教材和受控识别/模型事件，未证明真实麦克风、噪声环境和远端模型质量。没有实现自动教材位置估计、AI 结构候选、自动数学/图文识别或笔记文档包交换。来源多时仍按 100 条分页，全文读取成本需要在长课堂实际数据上继续观察；读取失败可手动“读取最新笔记”重试，未引入定时轮询。
