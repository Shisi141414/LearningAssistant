# PDF 原页选区配图

> 2026-11-12 · 设计与报告：codex · 人工选区配图首批交付

## 复用决策

查阅 [PDF.js 官方渲染示例](https://mozilla.github.io/pdf.js/examples/)、[react-pdf-highlighter 选区实现](https://github.com/agentcooper/react-pdf-highlighter/blob/main/src/lib/get-area-as-png.ts) 及其 [依赖](https://github.com/agentcooper/react-pdf-highlighter/blob/main/package.json)。现有应用已使用 PDF.js 6，后者依赖 PDF.js 4 并附带整套多页批注界面，直接引入会重复阅读器及引擎。优先直接复用已有 PDF.js、canvas 与附件保存；借鉴社区的画布选区路线，自行实现本项目需要的少量坐标与 IPC 适配，不拷贝另一套解析器或截图工具。

## 数据及边界

选择 PDF 实际页序号与可见旋转页面中的归一化矩形。主进程只接受版本 ID、页码和矩形，不接受任意路径或图片字节；工作线程校验原件散列，再从该 PDF 渲染区域为 PNG。保存页码、选区、原始 PDF 坐标、旋转、页面尺寸及 PDF.js 引擎版本，复用不可变图片附件和人工条目引用。扫描 PDF 可选区；这不是 OCR、自动配图检测或语义识别。

复用现有附件表，无需重建来源或改旧迁移。PDF 选区可分次增加附件，不覆写 Office 一次提取记录；取消/失败清理本批文件，不发布半份附件，退出不自动重启。每文档仍最多 100 个图片附件 / 50 MiB，单图最多 8 MiB / 1600 万像素，单次只运行一个配图任务。重复保存同位置复用已有附件，原件、来源、修订和证据保持不变，关联到条目才生成新修订。

## 界面设计

沿用学习文档主题：正文 #1f2328、辅助 #6b7280、边线 #e5e5e0、背景 #f7f7f5、选区 #4f46e5；宋体正文、黑体标题。保持现有“文档配图”折叠区，在 PDF 中显示页码输入及“选择 PDF 配图”入口；原页左对齐，拖动矩形呈半透明紫色边线。提供百分比位置与大小输入，支持不使用鼠标的操作；保存、清除与取消使用直接动作名称。图注与归属仍在条目整理中确认，不新增独立编辑器或装饰性面板。

```
文档配图
  PDF 页码 [26] [选择 PDF 配图]
  原页 / 框选区域
  左/上/宽/高百分比 [应用选区]
  [保存选区配图] [清除选区] [取消保存]
  已保存配图与原页位置
```

## 验收计划

验证矩形/页码/IPC 边界、旋转及非零页面原点、像素内容对应、原件散列变动拒绝、重复复用、数量/容量限制、取消和事务失败恢复、旧来源/证据不变；实际应用拖动选择、百分比选择、图片显示、图注与历史、1024 宽与重启。真实热力学扫描 PDF 选取区域，核对页码和可见内容；不以单区域成功推断整书图像理解完成。

## 使用与设计说明

材料库 → 学习文档 → 展开“文档配图” → 输入 PDF 实际页序号 → 选择 PDF 配图。拖动框选或填写左侧/顶部/宽度/高度百分比并应用，保存选区后在对应条目的“整理条目”中选择图片、写图注并保存。修改百分比或页码会清除旧选区，避免输入值与保存区域不一致。条目图片下“查看配图原页”会显示原页并标出只读选区，历史修订也可回看。

选区存 `[左,上,宽,高]`，数值是页面比例，故窗口缩放和高分屏不会改变来源位置。PDF 本身的坐标以左下角为基准，且可有旋转或不从零开始；因此保留可见页比例的同时，由 PDF.js 转换保存原始坐标及旋转。图片在工作线程独立按最高约 144 DPI 渲染，仅创建选区画布，限制长边约 4096 像素；预览清晰度不决定保存结果。选区引用和教材条目文字来源分别保留，不能把扫描图当成识别出的正文。

新增六项逻辑回归：严格输入、四种旋转与非零页面原点的实际色块像素、原件变动/无效页码/损坏文件、分批保存与重复复用/来源及证据保留、取消/事务失败清理、文档总数量/容量限制。实际 Electron 验证真实鼠标拖动、百分比输入、越界禁存、后台取消、重复保存、图片读取、人工归属、历史只读、原页选区回链、1024 宽及跨进程重启。`npm test` 通过 77 项逻辑回归及实际首次/重启集成检查；`npm run typecheck` 和构建通过。截图核对修复了预览宽度不足的问题，确认保存的图形与图注没有裁切。

真实材料验收使用隔离数据库导入 353 页热力学扫描 PDF，建立 353 个来源占位，保留原件和未 OCR 的事实。从实际 PDF 第 28 页（印刷页码 8）保存 `[0.28,0.44,0.48,0.19]` 选区，人工核对为图 1-2“开口系统与闭口系统示例图”，闭口气缸/开口汽轮机、边界/进口/出口标记及图注完整。实际图片协议字节与登记散列一致，来源和修订不变，原件散列未变；关闭应用后重启附件仍可读取。测试没有重写用户数据库，也没有调用云模型。

本批提供人工选区与归属；自动检测图形边界、自动判断对应段落、图中文字识别、Office 矢量图转换、可移植交换包、课堂统一格式及 PDF 导出继续按计划建设。整页或区域仍是图片，不能用来声称可搜索的中文文字已被识别。
