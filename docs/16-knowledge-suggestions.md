## 本批闭环与边界

在教材语义条目或已保存的笔记原文/整理字段中，用户选择模型并显式发送此处文字，生成最多 8 个知识候选。每次一个来源、最多 12000 UTF-16 单元；不发送整本教材或已有知识库。主进程固定来源、正文、散列及模型信息，模型只提供名称、摘要、原文中的别名、连续摘录和建议引用角色。严格结构与摘录校验拒绝虚构来源、额外字段、过长输出及重复候选；只能抽取资料里有明确名称的知识，未命名概念留给人工处理。

生成不写入知识点。审核时逐条改名称、摘要、别名、学科、角色和说明，选择已有知识点或新建；已有知识点仅增加证据，不自动覆盖释义、别名或合并实体。新建与证据及采纳记录同一事务提交；重复点击不再建条目。名称相同的候选只作为匹配提示，同名多义由用户判断。记录模型候选、人工决定和结果，移除证据后不因重试而自动恢复。

学习来源固定修订，后续文档更新不改原候选；笔记发生变化/删除后仍可阅读候选快照，但禁止采纳旧文字，须重新生成。生成可取消、失败后手动重试；重启把中断任务标为已取消，不自动补发模型请求。暂停/退出、迁移数据期间遵循已有工作保护。历史最多显示最近 20 批。未接入全书自动抽取、实体合并或图谱。

## 界面设计

沿用学习阅读页的颜色：背景 #f7f7f5、正文 #1f2328、辅助 #6b7280、边线 #e5e5e0、操作 #4f46e5。正文宋体，知识名称/小标题黑体，导航沿用系统字。折叠“知识证据”内增加“助理提议知识点”；先展示模型、发送范围、生成与记录，再逐条展示原文摘录和可编辑候选。单列左对齐，长正文折叠；保留手动引用入口，不增加独立空页面。

布局：`此处来源 → [手动引用] → [助理提议：模型 / 生成 / 历史] → 候选名 / 摘录 / 审核字段 / 采纳`。按钮明确区分“生成候选（发送文字）”与“确认并采纳”；用文字状态和禁用反馈表达进度，不仅用颜色。1024 宽检查折行、键盘操作及错误提示。
