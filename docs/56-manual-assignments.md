# 手动作业与统一日程（2026-11-14）

署名：codex。这是 M4 作业管理首批；学校连接、同步预览及持续同步按[接入方案](55-assignments-and-campus-sync.md)继续建设。

## 现在可以使用

侧栏新增“作业”。可以新建与编辑名称、学科、具体要求、截止时间，以及未开始 / 进行中 / 有困难 / 已完成状态；有困难时填写原因。要求输入复用现有正文与公式混排编辑器。列表按截止时间排序，支持名称与要求搜索、学科筛选、未完成 / 逾期 / 全部 / 回收站及每页 50 项。

作业详情可进入同一任务的日程，使用既有学习资料关联、知识点引用、用时与前置任务、自动安排、时间块锁定及提醒设置。日程中可以修改作业任务，变更会回写；两边均能回到对方。日程说明也改用渲染后的公式编辑器。

这里的“已完成”是本地学习状态，不代表向学校提交作业。手动作业不会向学校写入内容。没有截止时间时仍可保存，用户自行在日程设置安排。

## 数据与协作保护

- 仅追加 migration 034，未修改 001–033。原 `assignments` 表保留，新增 `assignment_links` 唯一任务映射和 `assignment_history` 审计；不重建现有任务表或改变其已发布的 kind 约束。
- 名称、要求、截止、固定时间、本地状态和知识引用以同一条 `tasks` 记录为准。任务变更触发原子镜像、修订号变化和审计，日程或提醒中的编辑也使旧作业草稿失效。作业详情显示最近 100 条历史，完整历史仍保存在本地。
- 两侧保存与回收都检查修订号。陈旧输入被拒绝并保留；作业页明确选择重新载入才丢弃草稿。保存时阻止离开，关闭、链接导航、快捷栏跳转和窗口关闭对未保存内容有保护。
- 新页面和日程对未修改的截止显示保留原始秒/毫秒，不把只改名称或地点变成隐式修改截止时间。
- 旧版作业逐条映射，原值保存为固定快照。空名称、过长名称、未知状态及无效日期只在派生任务中规范化；不擅自覆盖旧行或丢失历史来源。迁移遇到错误全批回滚、修正后可重试，重启不重复创建任务。

## 回收、恢复与依赖

删除先移入回收站，保留作业、要求、来源、历史、知识和学习资料关联。原固定日程清除，当前学习时间块全部撤销（包括锁定块）；撤销前时间块写入作业历史，提醒在下次核对或投递前失效。日程中的删除也走这一流程，禁止绕过来源直接删除任务。

回收站显示原本的本地学习状态，恢复使用同一任务并恢复该状态；截止、要求和关联保留，旧固定时间与时间块不会自动复活。原自动安排配置保留，恢复后若仍启用持续安排，后续核对可生成新安排。

内部完成标志仅用于停止回收站条目的日历与提醒；规划器将回收作业视为不可用的前置任务，不能把“删除”当成“已完成”。依赖该作业的任务提示前置未就绪，用户可恢复作业或调整依赖。回收站作业禁止编辑、重新启用安排和直接删除。

## 开源复用与选择

本批沿用已有统一任务、FullCalendar、学习时间块规划器、提醒服务与 MathLive/Tiptap 编辑器，没有另建平行的日历或公式控件。学校协议采用已研究并完成当前账号只读验收的维护库，比较、协议与版本证据见[网络学堂选型](55-assignments-and-campus-sync.md)。
