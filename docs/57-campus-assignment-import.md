# 网络学堂作业导入与更新（2026-11-14）

署名：codex。承接 [手动作业](56-manual-assignments.md) 与 [开源调研、真实兼容性前置](55-assignments-and-campus-sync.md)。本文交付官方登录、手动读取、差异预览和确认导入；定时持续同步另批实现。

## 使用与边界

作业页展开“网络学堂作业”，连接后在学校官方窗口完成账号登录与二次验证。选择当前学期的课程、对应本地学科，读取并预览，最后确认所选项。新作业的本地状态默认为未开始；学校已提交的新作业默认不勾选，可以手动纳入。学校“已提交”只作为来源信息，本地进行中、已完成等状态独立保留，不代交作业。

已存在作业的名称、截止时间、课程对应学科可跟随学校更新。用户在作业页或日程改过的字段默认为人工保护；预览显示本地值和学校值，只有明确勾选该字段“采用学校值”才清除保护。学校列表没有提供的本地要求、学习时间、资料引用、完成状态不会被来源更新覆盖。课堂/知识内容仍使用已有内部格式，与作业关联继续使用统一任务资料入口。

同一账号、课程、学生作业记录只映射一项本地作业和一个任务；基础题目编号不是去重键。重复读取不复制任务。回收站记录继续占有来源键，读取不能自动复活；某门课失败单独报告，不根据读取缺项删除任何本地记录。

预览十分钟有效，绑定当前窗口、账号、数据库、课程配置、任务修订、来源修订和人工保护。预览后其他页面修改作业/学科，确认导入会拒绝并要求重新预览，不拿旧草稿覆盖新内容。确认采用整批事务；一项失败则整批回滚。断开连接会取消读取并销毁待确认预览，已导入的作业保留。

## 复用选择与认证隔离

直接使用 MIT 的 [@robertying/thu-learn-lib 8.0.0](https://github.com/robertying/thu-learn-lib)，不移植整个 learnX，也不自行实现 SSO/密码加密。库的 ESM 模块在主进程原生动态加载，Electron 会话 Cookie 通过 [Session.fetch](https://www.electronjs.org/docs/latest/api/session#sesfetchinput-init) 复用。库的三个作业列表和优秀作业列表使用 POST 读取；业务读取适配器只允许审阅过的学生读取路径、方法，拒绝重定向和未审阅的写操作。

官方认证窗口没有应用 preload，关闭 Node 集成、启用上下文隔离和 sandbox，拒绝权限请求与非学校 HTTPS 导航。每次连接使用新的非持久会话；Cookie、CSRF 只留主进程内存，重启后重新登录。断开会清理该隔离会话，不注销浏览器或其他应用的学校登录。退出先取消学校工作，迟到结果不能重新打开已关闭的数据库。

实际检查发现未登录时直接打开课程主页会停在学校“登录超时”页，入口因此改用该发布库已审阅的官方 `ID_LOGIN` 地址；已观察到“清华大学用户电子身份服务系统”窗口。认证完成后才读取课程主页与令牌。打开认证表单本身不等于当前业务连接已验收。

库返回的姓名和院系不能当唯一账号。当前实现仅支持官方账号表单：从本窗口向精确官方认证接口发出的有界请求中提取 `i_user`，立即作带命名空间的 SHA-256 标识；不存原账号、密码或请求体，不向渲染页返回它们。此标识用于本机去重，不是匿名化承诺，也不替代学校认证。登录别名按各自标识隔离，不猜测合并；无法获取表单身份的二维码等流程明确拒绝关联，需要使用账号表单。学校认证形式变化时必须重验。

学校数据仍是个人学习资料：本地只保存作业标识、题目基础编号、标题、原截止字符串与校验后的毫秒时间、提交标志、课程/学期以及重建的官方详情链接。学校响应中的成绩、评语、优秀作业内容、教师信息不进入来源表或普通日志。原始教材和手工内容不受该过程改写。

## 数据与学习说明

仅追加 migration 035，001–034 保持不变：

- `campus_accounts`、`campus_courses`：本地账号范围、显示信息和课程学科配置；配置有独立修订。
- `campus_sources`：学校记录到既有作业的唯一映射、当前来源快照、人工保护字段。
- `campus_source_versions`：上述最小来源快照的不可变版本，散列去重。
- `assignment_links.mutation_origin`：区分来源更新与人工修改；字段变化触发器同时覆盖作业页、日程和直接任务更新。

原有 `writing` 只控制审计抑制，人工保存也会使用它，所以不能用它判断“谁改了字段”。单独添加来源标志，才能在同步事务中跳过保护标记，同时让日程里的手动修改可靠产生保护。来源更新后即使只有学校提交状态变化，也会更新作业修订，避免打开的编辑窗口拿旧来源误操作。所有来源导入和更新追加历史，不修改过去记录。

读写分成两阶段：异步只读请求与本地预览，最后短同步事务确认。网络慢不会占用课堂转写主循环；窗口/连接取消和超时通过 AbortSignal 终止请求，数据目录切换通过已有工作登记防止跨库写入。
