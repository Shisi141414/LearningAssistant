# 习题集文件导入与自动切分

工作报告：codex · 2026-11-13

## 使用流程

在习题库点击“导入习题集”，选择学科和 PDF / DOCX / PPTX / DOC / PPT 文件，也可以选择已有材料及其具体版本。原件按材料库规则保留，解析完成后自动预览题目。核对题面、思路、答案和来源，勾选需要的题目后确认转换；可先导入部分，再继续导入其余题。按材料实际学科归属创建习题，不因列表筛选而改动材料所属学科。

题面、解题思路和标准答案写入既有内置文档格式，用户答案、错误原因和复习知识关联留空，状态为“未完成”。不猜测对错，不生成或补写标准答案。后续可以使用原有编辑、来源定位、修订、回收站、知识关联与 PDF 导出。

关闭预览不创建习题或切分修订，已经导入的材料与原件仍保留，可从已有材料继续。扫描 PDF 可以在同一导入面板进行既有 OCR/校正后选择派生版本；DOC/PPT 使用既有 LibreOffice 转换设置及重试。不会自动下载模型或安装转换工具。

## 开源方案与选择依据

实施前查看 [Docling 格式支持](https://github.com/docling-project/docling/blob/main/docs/usage/supported_formats.md)、[Docling 仓库](https://github.com/docling-project/docling)、[社区提问](https://www.reddit.com/r/LocalLLaMA/comments/1o1gmgf)与 [calibre 结构识别](https://github.com/kovidgoyal/calibre/blob/master/manual/conversion.rst)。这些项目能提供文档解析或标题边界识别，但题目/解答语义与本项目固定修订、`solves` 关系、用户作答隔离的契约不同；直接搬入转换框架会重复现有功能。

按“直接使用 → 迁移 → 修改 → 自己写”，直接使用现有 PDF.js、OfficeParser、LibreOffice/OCR 工作线程与材料托管流程；修改既有习题转入逻辑，使明确标为思路的解答进入“解题思路”，其余解答进入“标准答案”，配图也按该角色保留。新增的局部逻辑只负责题号边界、预览凭据与批量提交，不增加解析依赖，不复制外部项目代码。

## 切分规则和数据保护

- 新的未整理来源按行识别 `1.`、`1、`、`1-1`、`第1题`、`习题1`、`例题1`、Exercise / Problem / Question 等题号；括号小问留在原题内，续行和跨来源正文合并。数字小数行不会仅因小数点被当成题号。
- 识别思路、提示、解答、答案等标记；汇总答案只在题号唯一时配对。重复章题号或无法对应的答案保留在材料中并提示，不猜测归属。
- 保留题号前的说明与无法识别的内容。生成切分使用来源范围引用，执行全部原文恰好覆盖一次的现有校验；不改写、删除原文。没有明确题目就提供整理入口，不将整本文件硬转为一道题。
- 已有人工或 AI 结构、公式/配图校正与解答关系优先，直接列出既有习题/例题，不重新切分它们。
- 预览凭据属于发起窗口，有效期 20 分钟，新预览或取消使旧凭据失效。提交复核材料可用状态和基础修订，旧预览不能覆盖后来整理。
- 发布材料切分修订和创建所选习题位于同一数据库事务；任何一题失败则整批与切分修订一起回滚，可修复后重试预览。
- 固定版本/修订/条目按既有来源键去重；重复导入不覆盖用户答案，已在回收站的题不复活。不同材料修订仍是不同来源，不做跨版本相似题合并。
- 同批次共用一次来源文档读取与校验。原题快照仅保存所用字符片段，并在位置元数据中记录原来源 ID 与 UTF-16 范围；题目引用、公式与配图保留，不将同一整页或大段来源在每题重复存储。完整原件及材料原始来源仍由材料库保留。旧的全来源快照仍可读取，无数据库迁移。

## 约束与验证

沿用文件 50 MiB、学习文档 1000 来源 / 200 万字符限制；一次最多 500 题，预览每组 25 题，每个题面/思路/答案最多 20 万字符。切分为确定性规则，不表示完整教材理解；多栏 PDF、没有题号的练习、答案散落、复杂公式与图像内容仍需核对。已有明确关联的公式/配图随习题保存；未关联图片可回到材料整理后重试，不凭页面相近猜测题图关系。

新增单元验收覆盖原文覆盖、跨页、小问、中英文/全角/章题号、汇总答案歧义、人工结构保护、预览取消与窗口隔离、部分导入/去重/用户答案和回收站保护、整批失败回滚与重试、陈旧预览/删除材料、IPC 参数拒绝。真实 Electron 验收覆盖文件选择器取消、DOCX 自动切分及公式预览、选择部分后继续导入、真实 PDF/PPTX 解析、来源固定修订、1024px 布局与重启去重；测试原文件摘要保持不变，验收期间外部 HTTP/HTTPS 请求为零。

单独运行：`npm run test:exercise-sets`；该回归也加入完整 `npm test`。

最终类型检查、生产构建与完整 `npm test` 通过；190 项检查零失败、零跳过，教材/课堂/笔记/项目/日历/习题/图谱/项目文档及新增习题集的真实 Electron 和重启验收通过。实际交付记录为本批实现范围，不将合成样例当作所有教材版式的质量保证。

容量回归实际转换一份约 80.8 万字符、500 题的来源，确认单题快照没有重复整份来源，且第 501 题会明确拒绝。单次本机样例耗时约 0.47 秒，仅为该样例测量，不代表所有扫描件或版式的性能保证。
