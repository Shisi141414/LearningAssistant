PDF 使用原第 28 个 PDF 页面（印刷页 8）的图 1-2，归一化选区 `[0.28,0.44,0.48,0.19]`。图片的页码、坐标、旋转、引擎和散列随包保留。教材原件不修改，未做全书 OCR；空文本来源仍保留页面位置，不将其声明为教材文字理解完成。

验收时的“跨目录标记”、概念释义和人工配图归属仅用于测试存储与引用，不是对原教材作出的学术校订，也不证明自动图文归属正确。

## 可重复检查

扩展已有 `scripts/test-real-materials.cjs` 的本地配置选项 `packages: true`（与 `restart: true` 配合）。在原有真实材料导入、查询、配图与重启检查上，追加导出、独立空目录导入、转换器不可用、重新映射引用、重复导入及新目录重启检查；没有新增第三方依赖，也没有向默认自动化测试中加入私人教材路径。

本地配置示意：

```json
{
  "converterPath": "<本机 LibreOffice soffice 路径>",
  "restart": true,
  "packages": true,
  "cases": [
    { "path": "<扫描教材.pdf>", "kind": "textbook", "learning": true, "expectOcr": true, "crop": { "page": 28, "rect": [0.28,0.44,0.48,0.19] } },
    { "path": "<旧课件.ppt>", "kind": "slides", "learning": true, "assets": true, "query": "热力学" },
    { "path": "<旧讲义.doc>", "kind": "handout", "learning": true, "assets": true, "query": "十字轴" }
  ]
}
```

运行 `node scripts/test-real-materials.cjs <本地配置.json>`。四个实际应用进程全部通过；结果标记为 `REAL_MATERIAL_TEST_OK`、原目录 `REAL_MATERIAL_RESTART_OK`、`REAL_PACKAGE_TEST_OK`、新目录 `REAL_MATERIAL_RESTART_OK`。运行时生成的原件副本、文档包、配置、数据库和完整结果保存在被忽略的本地/临时目录，不提交到 Git。另运行类型检查和构建。

## 保留的质量边界

PPT 尚有 1 处、DOC 尚有 60 处未支持的图片对象（含非 PNG/JPEG 或未暴露的内嵌对象）；警告随包保留，原件和转换产物可以对照。通过包往返只证明已保存内容不丢失，不能消除前一步解析器的缺失；不把 27/10 张图片当作所有图形或公式已经提取。
