# 学习文档公式校正与内容节点

> 2026-11-12 · 设计与报告：codex · 人工公式校正首批

## 复用与范围

复查 [OfficeParser 的结构化解析器](https://github.com/harshankur/officeParser/blob/master/README.md) 和本机 8.7.1 的 `CodeMetadata.math`；有数学节点的输入可以保留 LaTeX，但不能据此推断扫描 PDF、旧课件或 DOCX 中的公式已被正确识别。本批先提供人工公式校正，不自动从 OCR 文字猜公式，也不升级解析器或另写数学排版器。

直接复用已有 [KaTeX](https://katex.org/docs/options.html)，遵循[社区对公式资源边界的讨论](https://gitlab.com/gitlab-org/gitlab-foss/-/issues/61410)：不信任公式中的链接/图片/HTML 命令、限制展开和尺寸，错误显示原式，不执行外部内容。扫描/原生公式提取和图片节点另批验证。

## 数据与来源

条目增加可选 `formulas`，每项为连续原文范围 `[start,end)`、`latex` 和行内/独立显示方式。范围以该条目的 `entryText` 为基准，使用 UTF-16，必须非空、不重叠、不切断字符；公式之间的文字从原来源直接取出。由程序生成文本/数学内容节点供阅读和后续导出，原文及全部来源覆盖规则不变。旧快照没有该字段时按原方式显示。

保存或移除公式生成不可变修订，保存公式标为人工确认。公式为人工校正排版，不能当作原始识别结果；原文对照始终可展开，知识证据和 AI 知识候选当前仍引用原始来源文字，并明确提示。语义 AI 不能替换带公式的条目。拆分/合并带公式条目前先移除校正，防止范围漂移；改标题、章节及证明关联保留校正。每条最多 20 式、每式 2000 字符、全篇最多 200 式，校验错误不发布。

## 界面设计

沿用正文 #1f2328、辅助 #6b7280、边线 #e5e5e0、背景 #f7f7f5、操作 #4f46e5；正文宋体、标题黑体、说明楷体，公式使用 KaTeX 自带数学字体。在“整理条目”内复用原文选择框：选择公式对应原文 → 输入 LaTeX → 选择行内/独立 → 预览并保存。原文和公式左右无需额外面板，保持当前阅读宽度；长公式在本条内部滚动。已存公式提供编辑和移除按钮，不要求用户操作 JSON 或字符下标。

```
来源原文 [选择一段]
公式校正 [LaTeX 输入]
[行内 / 独立]   公式预览   [保存公式校正]
```

此处重点是原文范围与预览一一对应，沿用既有阅读样式，避免引入与笔记无关的装饰或新编辑器。验证字符范围、重叠/替换/移除、坏公式、人工保护、来源/证据/旧修订不变、实际选择与渲染、中文与长公式、1024 宽和跨进程重启。

## 使用与当前边界

材料库 → 学习文档 → 整理条目，在来源文字框选中 `F=ma` 等内容，在下方“公式校正”输入如 `F=m\frac{\mathrm{d}v}{\mathrm{d}t}`，检查预览再保存。再次整理可编辑或移除已有公式；改选原文用于添加新公式，编辑中的公式须先点“改为添加新公式”。本篇搜索同时匹配来源文字、标题与已保存 LaTeX。没有公式校正的旧条目保持现有阅读方式。

独立公式上下留白保证分式的上下缘完整；长公式只在条目内部横向滚动，不撑开窗口。原文对照标明人工校正及知识证据使用范围。当前不支持直接对纯图片/无文字扫描页选区校公式，先 OCR 或对照原件；不会自动认为 `F=ma` 与修正公式语义等价，正确性由用户核对。

新增七项逻辑回归覆盖节点复原、UTF-16/字段/范围/数量约束、KaTeX 与禁用外部内容、保存替换移除、人工保护、全篇限制、严格 IPC 及数据库重开。实际 Electron 走文本选择与表单保存，覆盖分式/MathML、坏预览禁用保存、编辑/移除、长公式横向容纳、历史只读、校正搜索与跨进程重启。截图检查修正了分式高度不足造成的纵向滚动条，并加入尺寸回归。模拟讲义验证机制，不替代真实教材数学正确率验收。

`npm test` 通过（64 项逻辑回归及含构建、两次实际 Electron 进程的集成检查）；`npm run typecheck` 通过。已核对 1024 宽截图、短分式没有纵向溢出、长公式在条目内部滚动；未调用云模型，未改动真实教材或用户数据库。

图像附件节点、自动数学提取、完整交换包、课堂笔记统一和 PDF 导出继续分批构建，本批不宣称内部格式已全部完成。
