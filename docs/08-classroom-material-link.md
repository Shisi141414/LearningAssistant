# R2 课堂材料联动

作者：codex · 2026-11-11

## 开源方案复查

阅读器直接复用 [PDF.js 官方示例](https://mozilla.github.io/pdf.js/examples/) 的页面读取/渲染 API；不另写 PDF 解码器。社区 [React 下并发渲染同一画布的讨论](https://github.com/mozilla/pdf.js/discussions/17355) 提醒需要取消旧任务并隔离画布。已有 pdfjs-dist 依赖可直接复用，无需为了单页预览再加入一套不同版本的 PDF 引擎。

旧格式的候选链路为 **保留原件 → LibreOffice 转换 DOC/PPT → DOCX/PPTX 提取文本，或 PDF 展示排版 → 条目化**。[官方参数文档](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html) 提供 headless、convert-to 和独立 UserInstallation；调用现有程序比拆取依赖布局引擎的格式过滤器更适合本仓库。该成本判断是工程推断，不代表格式保真已验收。若以后复制/分发其代码或二进制，应按 [LibreOffice 许可证](https://www.libreoffice.org/licenses/) 保留对应声明并核对具体组件。

扫描件另走 OCR。[OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) 能为扫描 PDF 增加文字层，再接入现有 PDF.js 解析；Tesseract/Docling 也是候选。转换本身不能把扫描图像变成可搜索文字；有文字层的文件不必重复 OCR。社区 [Gotenberg 的 LibreOffice 转换问题与修复记录](https://github.com/gotenberg/gotenberg/releases) 说明页尺寸、公式、进程回收及外部资源需要实样验收。

本机未发现 LibreOffice/Tesseract。本轮不安装整套转换环境，也不宣称 OCR/DOC/PPT 已实现；后续接入需覆盖：独立配置目录、固定参数且不经过 shell、超时/子进程清理、外部资源与宏策略、原件及转换产物关联、字体缺失告警和离线模型分发。先采用可插拔外部转换器，确有部署问题再考虑迁移或修改源码。

## 实施前的界面设计

沿用现有调色板：背景 #f7f7f5、正文 #1f2328、辅助字 #6b7280、边线 #e5e5e0、交互 #4f46e5；字体沿用系统中文字体，正文 14–16px。所有阅读内容左对齐，不增加装饰性统计图。

课堂主体为等宽双栏：左材料、右转写，两侧独立滚动；右侧底部输入，顶端保留录音和结束课堂。准备页就能挑材料并设置本讲起点。PDF 显示原页并附提取文字；Office 暂显示结构化文字，原排版通过“打开原件”查看，明确能力边界。

关键交互是**浏览位置与讲授位置分开**：翻页只改变阅读器；按“校准到这里”才更新后续转写的来源。点击历史段落的来源可回看教材，不暗中改写当前讲授位置。记录保存时快照引用稳定块 ID，旧段落不会随校准或教材更新漂移。

## 数据与验收计划

迁移 v6 增加课堂会话、当前讲授位置、校准事件、段落来源关系。校准前先收尾未结束的语音片段，使尾句归属旧位置；以后段落使用新位置。整理只读取段落当时引用的附近条目，不采用重试时的当前页；原转写始终保留。

验证目标：课前起点、人工换页/切材料、脱离教材、旧引用保留、材料到笔记回链、重启恢复位置、原件 PDF 实际渲染、非法位置拒绝、附近材料进入整理提示且不覆盖原文。真实麦克风长时使用和教材复杂排版仍需单独验收。

## 本轮交付与验证

- 追加 v6 迁移；原文段落保存时关联不可漂移的块 ID。校准前先 flush 尾句；翻阅/回看不改变游标。段落整理读取保存时位置的前后条目，并提示只校对术语、不伪造讲授内容，原转写独立保存。
- 准备页可选材料、版本与页/幻灯片/条目起点。课堂左右分屏、各自滚动；记录可回看来源，材料可回到相关笔记。结束后或从笔记可继续课堂，恢复保存位置。
- PDF.js 显示原页，并复用同一文档进行换页；DOCX/PPTX 当前仍是文字阅读与原件外部查看，不声称版式已统一。只读文件协议验证请求来源与路径范围；没有新增转换工具安装或模型下载。
- 额外修正手动记录保存失败时清空输入，以及补整理后课堂未刷新内容的问题。语音引擎启动失败时保留手动课堂与工作锁。
- `npm test` 通过：14 项逻辑/可靠性回归，以及真实 Electron 主进程、preload、renderer 与工作线程的导入和课堂交互测试。覆盖真实 PDF 绘制、准备页起点、翻页不校准、实时校准、历史来源不漂移、双向回链、最小窗口布局、失败草稿保留、资源越界/非法来源拒绝。
- 实际关闭并重开隔离应用，验证解析恢复、位置与旧引用保留、继续课堂追加记录及异常会话收尾标记。类型检查与生产构建通过，检查了实际课堂截图。

样例为临时生成材料，未读取用户资料或真实 API Key。模型响应、尾句和冲突等逻辑使用可控测试；不能代替真实模型纠错质量、麦克风长时转写或复杂教材版式验收。OCR 与旧 DOC/PPT 转换仍待接入。

## 下一步方向修订

用户补充：导入后统一为应用内“学习文档”，按一般叙述、定义、定理、命题、证明、解答、配图等语义条目存储/检索，并按类型使用不同字体与颜色；保留原件。接下来复查开放文档结构，确定可版本化的语义格式、来源映射、图文关联和 AI 分类审核机制。格式转换/OCR 是输入适配，不作为最终知识组织方式。
