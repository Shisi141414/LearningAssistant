# 可移植学习文档包

> 2026-11-12 · 设计与报告：codex · 编解码与契约已实现，应用入口待接入

## 复用与交付顺序

比较 [yauzl](https://github.com/thejoshwolfe/yauzl)、[yazl](https://github.com/thejoshwolfe/yazl)、已有 [fflate](https://github.com/101arrowz/fflate) 及其 [ZIP64 大尺寸问题](https://github.com/101arrowz/fflate/issues/298)，并查阅 [Ajv Schema 校验](https://ajv.js.org/json-schema.html) 和 [JSON Canvas 的公开数据路线](https://obsidian.md/blog/json-canvas/)。直接使用 yauzl 的惰性条目/尺寸检查和 yazl 的流式 ZIP 写出，不自写压缩或 ZIP 解析器；复用 image-size/canvas 检查图片，Ajv 校验字段，已有来源/章节/公式校验检查语义。打包/解包必须运行在工作线程，避免阻塞课堂。

本批锁定 yauzl 3.4.0、yazl 3.3.1、Ajv 8.20.0；已存在的 Ajv 同版本转为运行时依赖。未替换现有 Office/PDF 解析器，也未安装外部 Skill。

按“编解码与契约 → 原子保存及应用入口 → 真教材跨数据目录验收”小批提交。首批已形成可测试、公开的文件契约、可靠编解码器及实际 Electron 工作线程，不将库级读写冒充应用中已能导入导出。

## 文件契约

采用标准 ZIP，扩展名 `.ladoc`；根目录 `document.json`，原件 `source/original.<格式>`，旧 Office 转换产物 `source/converted.<格式>`，配图 `assets/<附件编号>.<png|jpg>`。格式标识仍为 `learning-assistant/document`，版本 `0.2`，以 [运行时 Schema](../shared/learning-package.schema.json) 为准；0.1 是原件/散列占位的旧草案，不将占位样本当成可导入材料。

导出用户所选的**固定修订**，包括原件、已存在的旧格式转换产物、规范来源、条目/章节/证明与解答关系、公式校正、配图/人工图注、OCR 原文与校正页、文中相关的已确认概念别名及该修订的知识证据。不打包 API 密钥、录音、无关概念、未采纳 AI 候选、课堂笔记或所有历史修订；完整应用备份是另一个用途。条目正文由来源范围生成，避免同时保存两份可以独立变更的权威正文。

包内来源、条目和概念 ID 维持相互引用。导入到现有应用时新建独立副本并一一映射本地 ID，保留包散列、原文档/版本/修订标识，不覆盖旧材料。概念内容和别名完全相同可复用已有同学科概念；同名但内容不同不能自动合并。用户在预览摘要后决定是否携带知识概念。再次导入相同包到相同学科应打开已有副本；导入到另一学科可建新副本。

## 校验与恢复

只接受声明的规则包路径；拒绝绝对路径、穿越、重复/大小写冲突名称、目录/符号链接、加密条目、未声明附件及缺失文件。先限制压缩文件 192 MiB、解压总量 176 MiB、JSON 16 MiB、最多 103 个文件，再按实际读取字节限流；原件/转换产物各不超过 50 MiB，图片各 8 MiB / 1600 万像素、合计 50 MiB / 100 个。逐文件核对 SHA-256 与尺寸；散列证明传输一致，不证明教材观点正确或作者身份。

Schema 拒绝未知字段/版本，语义校验检查来源 ID/序号/全部覆盖、章节、关系、公式、附件归属、PDF 选区、证据摘录散列以及概念引用；图片实际解码验证。文件先写入本批独立托管目录，全部通过再登记数据库，失败/取消仅清理本批文件。导出写临时文件后才替换用户指定目标，失败不损坏已有文件。关闭期间禁止发布未完成导入。

## 界面计划

沿用宋体正文、黑体标题和既有学习文档配色：背景 #f7f7f5、正文 #1f2328、辅助 #6b7280、边线 #e5e5e0、动作 #4f46e5。阅读器工具栏提供“导出所选修订”，材料库提供“导入学习文档包”。使用系统文件选择/保存框，不要求用户操作路径或 JSON；导入预览显示标题、原件、学科建议、来源/条目/配图/概念数量，提供学科选择、确认导入及取消。进度/失败提示使用已有正文区域，不新建装饰性页面。

```
材料库 [导入材料] [导入学习文档包]
预览：标题 / 原件 / 来源与条目 / 图片 / 概念
目标学科 [选择]  [携带相关概念]  [确认导入] [取消]
学习文档 · 修订选择 · [导出所选修订]
```

## 验收计划

真实 ZIP/中文名/公式/配图/OCR/别名与证据往返、选定历史修订、文件散列/字节一致；非法字段、来源遗漏、错误关系、损坏或伪造图片、路径穿越/重复/符号链接/加密/ZIP64/膨胀超限、取消及中途写入失败；已有文档、课堂链接和知识证据不变。应用入口需验证文件对话框取消、预览后确认、反复导入、跨学科/跨数据目录、导入重启可读及旧 DOC/PPT 无转换器可打开转换产物。任何一阶段未接通都明确记录。

## 编解码首批验证

新增 12 组逻辑回归：字段与语义边界、来源全部覆盖、章节/关系/公式/配图、OCR 原文与校正一致、别名与证据散列、真实 ZIP 字节往返、JPEG 与旧 Office 转换链、坏图片、路径/链接/重复/缺失/额外文件、CRC/本地名称/加密/ZIP64、实际膨胀字节超限、已有文件保护及读写中途取消。写出采用按实际读取内容校验的流，不能因源文件在导出期间变化而把坏包当成成功；读取使用固定 ZIP 字节快照，磁盘文件仅用程序生成的扁平名称。

故障测试发现 yazl 的惰性输入接口不自动转发输入流错误，导致坏散列时一直等待；已主动将校验流错误传到整个归档输出，并验证失败清理及超时回归。仅校验解压前声明尺寸仍不够，实际流持续限制字节并核对 CRC、SHA-256、图片头和真实解码尺寸。

`npm test` 通过 89 项逻辑回归及实际 Electron 首次/重启集成检查，`npm run typecheck` 和构建通过。实际应用测试从已保存的 DOCX 学习文档取固定修订和两处图片附件，工作线程打包/读取后逐字节一致；坏散列不会留下输出，当前文档不变，应用重启后仍能读取包。合成 PDF/OCR/公式及旧格式/JPEG 样本验证数据契约，不作为真实教材排版质量证据。

本批未新增数据库迁移或导入/导出按钮，未向现有用户库写入导入副本；预览确认、原子登记、概念冲突处理和跨数据目录的完整用户流程是下一批。生成的 `.ladoc` 默认忽略，测试与私密材料不入 Git。
