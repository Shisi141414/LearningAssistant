# 复习轮次与学习时间块（2026-11-14）

署名：codex。属于 M4 复习与 R5 自动排程的整合增量，接续 [FSRS 首批](53-fsrs-reviews.md)。

## 使用方式

在复习详情或日程的复习详情中展开“学习时间安排”，勾选“允许自动安排每轮复习”，设置用时和优先级后保存。默认关闭；每轮 5–120 分钟，使用五分钟网格，整轮安排为一个时间块。设置针对复习条目持续生效，不必每次评分后重新勾选。

保存后到日程页生成预览并确认；已有“持续自动调整”启用时直接沿用它的滚动范围、可用时段、每日上限、课程避让和历史。当前时间块可锁定、解锁、移除，并可通过日程已有入口填写时间或拖动。自动调整后的块列表可用“刷新安排”重新载入，未保存输入会提示确认；切换条目、页面操作与关闭编辑也保护正在保存或尚未保存的输入。

“建议复习时间”是**最早开始**，普通任务的“截止时间”是**最晚完成**。例如复习到期时间为周三 14:03，则最早可用网格为 14:05，不应为了赶所谓“截止”把它安排到上午。课程与有硬截止的任务先占用必要时间，再按复习到期先后安排；没有合适空档时列出未安排原因，不改写 FSRS 建议时间，也不假定已经复习。

## 开源复查与复用选择

直接使用现有 [ts-fsrs 6.0.0](https://github.com/open-spaced-repetition/ts-fsrs) 与项目已验证的 [Temporal 约束排程](45-auto-schedule.md)，不另写记忆模型或平行日程系统。[官方状态转换说明](https://open-spaced-repetition.github.io/ts-fsrs/guide/state-transitions)区分卡片到期与实际复习，模型状态在真实评分时推进；[调度器接口](https://open-spaced-repetition.github.io/ts-fsrs/api/ts-fsrs/scheduler)与[迁移指南](https://open-spaced-repetition.github.io/ts-fsrs/guide/migration)强调保留完整状态、日志与时间语义。

GitHub 社区方案比较了 [FSRS4Anki Helper](https://github.com/open-spaced-repetition/fsrs4anki-helper/blob/main/README.md)：它可在 Anki 中进行推迟、提前、负载平衡与休息日调整，但依赖 Anki 运行环境，并可重排卡片的到期日。这里要在现有课程日历中寻找到期后的学习空档，不需要迁移整个插件，也不应把日历移动当作模型重排。按“直接使用 → 迁移 → 修改 → 自己写”选择直接复用已有库与规划器；仅新增复习轮次归属、配置投影和事务归档。

## 轮次与数据边界

只追加 migration 033，既有 v1–v32 不修改：

- `review_planning` 是每个复习条目的唯一用时策略，保存修订与轮次编号；动态投影为统一规划选项，不重复写一份 `task_planning`，不另造任务。
- `review_block_cycles` 将现有 `schedule_blocks` 归属于某个复习轮次，预览、发布、移动与排程撤销均保留、校验轮次编号。
- `review_block_history` 保留因评分、撤销、暂停、来源不可用或停用安排而结束的旧块快照，包含原锁定状态。界面展示最近 20 批记录，数据库保留全部。

评分与撤销改变记忆模型时，在同一 SQLite 事务中归档并移除旧轮次所有时间块，生成新轮次；每轮用时策略继续保留。暂停、删除/回收来源和停用安排也关闭本轮，包括锁定块。这里的锁定保护同一轮内的普通重排，不能把已经结束的复习继续留在日历中。恢复复习或撤销评分不会直接复活旧锁，而是让新轮次依据当前课程与任务重新规划。旧安排仍能查看，不丢失历史。

时间块经过或结束不自动生成评分，不改变习题的用户答案、对错或记忆状态。同轮已经有过去/正在进行/保留的锁定块时，不因每次检查而不断新增重复块；若错过了安排，可移除原块后重新排程，实际回忆仍应到复习页评分。未锁定的未来块继续允许自动调整。位于本次滚动范围之外的同轮锁定块仍有效；滚动范围不是复习截止时间。

过期的预览或排程撤销不能复活旧轮次；手工移动即使选择忽略冲突，也不能早于 FSRS 建议时间。复习配置同时比较策略修订和卡片修订，旧表单提交拒绝且保留输入。复习不能作为一次性任务的前置依赖，也不能从通用任务规划入口伪造轮次。

后台变化进入现有排程变更计数器，持续排程在评分/暂停/配置变化后重新评估；手动预览期间仍按原规则暂缓自动发布。移除旧块使其持久提醒失效；建议复习时间本身的任务提醒沿用首批行为，不因日历占位改变。
