# LearningAssistant 产品总览

> 面向大学生的 AI 学习助手桌面应用——覆盖课前、课中、课后的完整学习闭环。
>
> 文档版本：v0.2（2026-11-11） · 初稿：claude · 扩展规划：codex
>
> 本文描述产品目标，初始基线见 [体检报告](05-health-check-2026-11-11.md)，当前增量见 [R0 修复](06-build-progress-2026-11-11.md) 与 [R1 材料库](07-material-library.md)；新增需求与验收见 [扩展规格](04-product-expansion.md)。

## 1. 愿景

把"上课听讲、课后整理、考前复习"这三个割裂的环节整合进一个应用：课堂上它实时转写并结构化整理讲授内容；课后它帮你管理知识、习题和作业；复习时它基于遗忘曲线主动推送该复习的知识点。全程有智能体（LLM）深度参与，但用户保持完全掌控。

目标用户：清华大学本科生（第一作者本人，理论与应用力学专业），Windows PC 优先。

## 2. 核心场景

### 课前
- 上传教材、补充材料 → 自动解析为可索引、带标签的结构化内容
- 课件、讲义、教材支持 Word、PDF、PowerPoint 等格式，保留原件与位置映射，按学科整理为内置条目
- 选择本讲材料与开始点（章节/页/幻灯片/条目），恢复或调整上次进度
- 智能体根据课程进度**预生成**可能被问到的问题与答案（课堂快速提问的缓存池）

### 讲座、会议与讨论（活动）
与课程共用同一套管线（实时转写、双视图笔记、标注、快速提问），但独立分组管理：活动次数多、每场主题独立跳跃，与课程"主题一致、前后连贯"的属性不同。每场活动是一个独立单元，可选关联到某学科，使讲座内容也能挂进学科知识网络（见架构 ADR-5）。

### 课中（课堂模式）
- 左半屏教材阅读、右半屏转写记录；课中可随时校准当前讲授位置，支持跳页、回讲与切换材料
- 结合当前教材上下文纠正转写与整理内容，保留原始转写，并把笔记链接到教材对应位置；点击来源可双向定位
- 实时语音转写，段落级纠改整理：定义、命题、例题、证明、解答、注意事项分色显示
- 每个语段可切换"整理视图 / 原文视图"
- 一键标注"重点 / 疑问"（转写流上即时插入，或选中已整理内容标注），标注点可追加备注
- 板书/PPT 拍照上传，图片识别后归位到对应段落
- 快速提问：选中内容或输入问题，智能体结合笔记、知识库、网络资源作答
- 导学助手：判断课堂内容重要度，提醒用户合理分配注意力（如纠结简单概念时提示先听讲）

### 课后
- 知识网络：知识点自动/手动关联，跨学科引用，图谱可视化；前置/推广/相关关系与习题/任务回链已接入，见 [交付记录](41-knowledge-graph.md)
- 习题库：与教材共用内置格式；每题包含题面、解题思路、标准答案、用户答案、对/错/未完成、来源、题型、错误原因、需复习知识点与无思路标记。基础录入、教材转入、修订与 PDF 见 [交付记录](40-exercise-library.md)，思路图示、AI 判题和笔记条目转入另行验收
- 作业与复习：手动作业/截止列表与唯一日程、回收恢复已实现，见 [作业管理](56-manual-assignments.md)；网络学堂只读同步在建设中。FSRS 复习及每轮学习安排已交付，见 [复习记录](53-fsrs-reviews.md)和 [时间块](54-review-learning-blocks.md)。
- 灵感库：随手记录创造性想法
- 全局快捷栏：任何页面底部"询问智能体 / 重点 / 疑问"大按钮

### 项目、日程与备忘（2026-11-11 新增）
- **项目**：助理管理项目要求、计划书、里程碑、任务、进度、项目文档与截止时间；跨学科关联知识、教材与笔记，帮助把所学用于实际项目，并将应用经验回链知识库
- **日程**：统一承接项目、作业、备忘和复习任务，结合可用时段自动安排与调整，支持锁定时间块、冲突提示、截止提醒和重启补发
- **备忘**：随手保存重要事情与知识点；智能体自动识别并进入已有知识库或日程，保留原文、处理状态和可撤销的归档记录，模糊条目进入待整理箱

## 3. 功能模块清单

| # | 模块 | 一句话描述 | 分期 |
|---|------|-----------|------|
| 1 | 课堂转写 | 实时语音→文本，段落级 AI 整理与分色 | M1 |
| 2 | 双视图笔记 | 每段落"整理视图/原文视图"切换 | M0（基础）/ M1（转写联动）|
| 3 | 快速标注 | 重点/疑问一键标注+备注，选中标注 | M0 |
| 4 | 知识网络 | 知识点抽取、关联索引、跨学科引用、图谱 | M2 |
| 5 | 快速提问 | 选中即问，预回答缓存 | M0（基础）/ M2（预回答）|
| 6 | 导学助手 | 课堂注意力分配提醒 | M4 |
| 7 | 知识库 | Word/PDF/PPT 等材料导入、扫描条目化、学科管理、原位引用 | R1（提前）/ M3 |
| 8 | 习题库 | 条目化习题管理，思路图示，错误点标记 | M3 |
| 9 | 灵感库 | 创造性想法记录 | M0 |
| 10 | 作业与复习 | learnx 同步 DDL、FSRS 复习调度 | M4 |
| 11 | 复习小组件 | 桌面推送待复习知识点 | M5 |
| 12 | API 配置 | ccswitch 风格：baseURL/上游格式/Key/模型导入+能力备注 | M0 |
| 13 | 活动管理 | 讲座/会议/讨论：独立分组、每场挂笔记、可关联学科 | M0（基础）|
| 14 | 项目系统 | 要求、计划书、进度、文档、任务与截止时间；知识应用关联 | R4 |
| 15 | 日程 | 自动排程与任务布置、冲突处理、可靠提醒 | R5 |
| 16 | 备忘 | 快速记录、智能识别、自动归入知识库或日程 | R6 |
| 17 | 教材课堂联动 | 左教材右转写、课前起点、实时校准、教材辅助整理与双向链接 | R2（人工）/ R6（自动）|

学科体系：现有笔记与会话可挂学科（subject）或活动（activity），也可不挂载；学科与活动是并列的分类维度。扩展后的项目可关联多个学科，通过引用连接已有知识与材料；备忘允许先进入收集箱再识别归属。知识网络支持跨学科引用，活动内容通过关联学科接入知识网络。

## 4. 非目标（v1 明确不做）

- 移动端 / macOS / Linux（架构不排斥，但不在近期计划）
- 多用户 / 云同步（纯本地单用户）
- 视频录制、屏幕录制
- 自己训练模型（一切模型能力通过 API 或开源推理库获得）
