## 数学输入（GeoGebra 风格，横向能力）

- `shared/mathPalette.ts`：七组符号面板数据（运算/模板/关系/逻辑/希腊小写/希腊大写/力学常用），共 90+ 符号
- `components/MathInput.tsx`：输入框 + [∑] 面板按钮；**模板类插入后光标自动落到第一个 `{}` 内**；多行模式带 KaTeX 实时预览（复用 MarkdownSegment）；点击面板外部自动关闭；单行模式（multiline=false）用于紧凑场景
- 接入四处：课堂手动转写、对话输入、底部快捷栏（单行）、灵感库。标题类单行框暂不接（布局考量，用户反馈后可加）
- 遗留：笔记编辑器（NoteDetail textarea）与项目目标等长文本编辑未接——等统一学习文档编辑器整合时一并处理
