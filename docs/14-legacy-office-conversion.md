# 旧 DOC/PPT 输入适配

> 2026-11-11 · 方案与实现：codex

## 选型与范围

按“直接使用 → 迁移 → 修改 → 自己写”，直接调用已安装的 LibreOffice，不移植格式过滤器，也不要求后台服务器。复查 [官方命令行参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html)、[Gotenberg LibreOffice 模块](https://github.com/gotenberg/gotenberg/blob/main/pkg/modules/libreoffice/libreoffice.go) 和 [LibreOffice 安全配置定义](https://github.com/LibreOffice/core/blob/master/officecfg/registry/schema/org/openoffice/Office/Common.xcs)。Gotenberg 证明该引擎适合服务化转换，但为本地桌面引入 Docker/HTTP 服务不合适；Node 自带子进程 API 足够做固定参数适配。进程清理仍需针对 Windows 子进程树验证，不能仅终止启动器。

原 DOC/PPT 保留为材料版本原件，转换的 DOCX/PPTX 是该版本的只读派生产物，单独记录格式、散列、引擎版本与时间。提取/课堂/学习文档读取派生产物，打开原件仍指向原 DOC/PPT。需要编辑转换文件时先另存，再作为新版本导入。转换后按同一语义格式整理，不引入第二套文档管理。Word 定位是转换后结构段落，PPT 定位是转换后幻灯片，不声称原 Word 页码保真。

本批调用本地软件，不打包 LibreOffice，也不使用 Word/PowerPoint COM 或云转换。软件缺失时保留原件并提示配置后重试，已支持的 PDF/DOCX/PPTX 不受影响。

## 任务与来源保护

- 复用材料队列、50 MiB 输入上限、工作锁及取消/重试/重启恢复。转换单独有两分钟限制，产物上限 50 MiB，校验非空 ZIP 签名，再交 OfficeParser 验证类型；不能只根据退出码判断成功。
- 固定输入文件名及参数数组，不经 shell。每次转换独立用户配置/输出目录，使用官方 Windows 控制台入口 `soffice.com`（选择 exe 时优先同目录 com）。后台隐藏窗口。取消/超时终止本次子进程树，不按程序名关闭用户正在使用的 LibreOffice。
- 独立配置禁用宏与活动内容，取消信任目录并阻止不可信来源外链。此配置不等于操作系统网络隔离，不能保证恶意文件绝不访问外部资源；产物中的远程资源仍由现有 OfficeParser 禁用。
- 产物验证完成、任务仍有效才登记转换记录；失败/取消不发布部分条目，原件不变。成功产物在解析失败后重试时复用，不重复转换。学习文档补来源也读取相同产物，并在工作线程检查已保存散列；产物被外部修改就拒绝重新解析，避免同一版本正文漂移。

## 实施前界面

延续材料库颜色、字体和布局。导入提示增加 DOC/PPT；材料库顶部折叠“旧版 Office 转换”区域，显示工具是否可用，提供“选择 LibreOffice 程序 / 自动查找”。转换结果在版本下显示工具版本、输出格式与“打开转换文件”，保留“打开原件”。未配置时就地说明到 LibreOffice 官网安装后选择程序，不弹额外确认框、不自动安装。

## 验收

先用模拟进程验证缺失工具、参数边界、坏输出、取消与超时，再用真实用户 DOC/PPT 验证原件散列、转换记录、检索、规范来源、重复导入与跨进程重启。独立下载并校验的 LibreOffice 仅解包到忽略的测试目录，不进入 Git。转换成功不等于图表/公式/复杂版式质量已验收，必须对照原件。

## 交付与结果

迁移 v11 追加转换记录，材料版本仍保存原 DOC/PPT 的格式与散列；派生文件另存并设为只读。材料库顶部提供工具检测/选择，版本下显示转换格式及工具版本，可分别打开原件和转换文件。主进程固定参数调用、工作线程提取与校验散列，课堂历史链接和已确认语义修订未重建。

- 完整 `npm test` 通过：39 项逻辑检查、数据库/整理/切块冒烟、真实 Electron 材料/课堂/概念/学习文档/AI 建议/转换配置界面和跨进程重启；类型检查与生产构建通过。模拟进程覆盖特殊字符参数、退出失败、输出过量、超时及取消后子进程树消失；越界清理拒绝，已登记产物不重新转换。
- 使用 LibreOffice **26.2.7.3** 的独立测试副本，经官方 SHA-256 校验后在 `out-tmp` 解包（未全局安装或入库）。真实热力学旧 PPT 得到 **53 张幻灯片 / 436 个检索与来源条目**；十字轴实验旧 DOC 得到 **80 个检索与来源条目**。关键词查询、来源建立、去重、原件和托管副本散列均通过。
- 截断的 DOC 转换失败时保留原件、不发布条目或转换记录；实际转换取消后原件仍在、无转换记录。再次关闭/启动应用并移除工具配置后，已保存转换、条目与学习文档仍可读；检查未残留本次 LibreOffice 进程。
- 1024 宽实际桌面界面无横向溢出；错误程序选择、缺少工具失败与原件保留在标准集成测试中验证。原件未上传，真实模型分类质量不在本批验收范围。

局限：未做复杂公式、OLE 嵌入对象、图片、字体替换和版式逐页保真验收；未验收恶意外链文件或强制终止操作系统后的进程回收。独立安全配置降低宏/外链风险，但不等于系统网络隔离。转换后的学习文档仍是规范文字来源，需要人工或可审核 AI 建议赋予语义类型。
