# 课堂导学：可回查的讲授线索

2026-11-14，codex。本批为 M4 规则版，已通过本地验收；不代表 LLM 混合导学或真实课堂准确率已经完成。

## 用法和边界

开始课堂后可开启“课堂重点提示”，设置 15–300 秒的提醒间隔。只处理开启后保存的新原始语段，既支持语音转写，也支持课堂手动记录。默认关闭；开启设置按笔记保留，结束课堂后停止处理，重启不会补扫或重播历史。

规则识别明确强调、易错、推导、考核、定义等用语，展示命中的词和原文摘录。强线索可以在课堂页提示；一般定义和推导开场只进入历史。相同语段十分钟内去重，强提醒有冷却间隔。否定和引号采取保守过滤，但中文语境、反问、转写错字仍可能误判，因此提示不是教师确认的考试要求，也不衡量用户是否专心。

用户可忽略、查看原句与其教材链接，或确认加入已有的重点/疑问标注。同类人工标注已存在时复用，保留原有评论。笔记页可以回查历史。原始语段变动后提示标为过期，保留旧摘录供比对，拒绝直接采纳；仅修改整理文本不使原始证据过期。删除原语段后保留无来源的历史，删除整份笔记才级联清理。

课堂卡片限制高度，说明和识别依据折叠，保留左右分屏空间。原句跳转只切换视图，不重新加载笔记标题；从统一文档切到原文后再定位，采纳标注只合并标注字段，不覆盖标题或段落草稿。

## 开源选择依据

按“直接使用 → 迁移 → 修改 → 自己写”检查：

- [Meet2Notes](https://github.com/estebanstifli/Meet2Notes)，MIT。检查提交 `b75077e588f5623d48d9c9bac05aa428b4257c52` 的 `application/live_assistant.py`、`domain/live_assistant.py` 和[实时助手设计](https://github.com/estebanstifli/Meet2Notes/blob/main/docs/live-ai-assistant.md)。其有界队列、触发词、冷却、关闭时清空队列可借鉴；Python 后端和依赖英文词边界的匹配不能直接接入当前 Electron 中文转写。本批迁移处理原则，复用本项目语段和标注服务，无源码复制。
- [lecture-companion](https://github.com/sumingze903/lecture-companion)，MIT。项目说明侧重英语浏览器转写、词典式中文提示，未提供直接适用的中文课堂强调识别。保留当前语音引擎和教材关联链路。
- [quint](https://github.com/poloniki/quint)，MIT。语义分块需要独立 Python 流程；本项目已有教材分块，本批无须替换。

同时检查 [Meet2Notes 社区问题](https://github.com/estebanstifli/Meet2Notes/issues)，安装依赖和自定义端点反馈不能充当中文课堂准确率证据。先落地小规模、可解释规则，以后再评估 LLM；本批没有新增运行依赖或额外网络请求。

## 实现与恢复

追加 migration 036：按笔记的开关/修订/冷却配置，以及带会话、原始语段哈希、规则版本、命中位置、摘录、采纳状态的提示。已发布 001–035 不改动。

原始语段提交后只入队，匹配在后续事件循环中运行，每次取一条，最多保留 32 条，溢出丢弃最旧提示任务并显示数量。规则只看末尾 4000 个 UTF-16 位置，最多保存四条证据。处理前再次检查课堂、数据库、配置修订、源哈希和会话代次；关闭、停止、重开课堂会清队列。过期语音回调按会话拒收。

提示失败不回滚已保存原文，界面显示错误；关闭后重开可重试后续新语段。待处理队列不落库，重启不恢复。标注采纳与提示状态更新在同一事务中，并校验修订和原文哈希，避免双击、多窗口覆盖及半写入。界面只在当前会话的新提示到来时播报，不在首次加载或历史分页时重播。
