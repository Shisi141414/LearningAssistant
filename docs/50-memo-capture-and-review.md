# 备忘首批：原文、识别与审核归档

日期：2026-11-14 · codex

## 使用闭环

任何页面底部“随手记”可离线保存文字与公式，选择学科或暂留待定；“保存并整理”进入备忘页。备忘可搜索、按待整理/已归档筛选、修改、查看原文历史、移入回收站与恢复。原有灵感库及其 ID、内容、选区上下文不迁移、不删除；旧记录可逐条“转入备忘”，同一来源只生成一条备忘，保留原记录时间。原灵感没有保存时区，转入修订明确记为未知；AI 时间候选被清空并要求手工核对，避免拿导入时间解释旧记录。

保存原文后，可以选择模型并“识别这条备忘”。模型只收到本条已保存修订的原文、修订保存时间与系统时区；密钥仍只在主进程。结果分为知识、待办、混合、项目想法或其他重要记录。程序检查 JSON 字段、名称和摘录的原文依据、ISO 日期及时区、起止关系；错误、取消或退出均保留原文。识别结果本身不改知识库或日程。

“填入整理草稿”后核对名称、学科、时间、地点及不确定项，也可完全手工整理。一条备忘本批可在一次归档中关联一个知识点并创建一个待办；不同知识可分次归档。命名知识须选择已有学科，已有同名/别名知识优先复用且不覆盖释义；多个候选时必须明确选择。无计划时间的待办进入待安排，有起止时间则成为固定日程；截止与计划时间分开。产生的待办使用现有统一任务与提醒系统，并引用同次选择的知识点。

归档先检查、再确认。检查不写入；固定课程与学习时间块均参与半开区间冲突扫描，首尾相接不算冲突，重合时必须明确忽略。确认绑定备忘修订、选择的知识、任务与时间块快照；期间变化拒绝旧确认并保留输入。知识、任务、来源关系与归档记录在一个事务中提交，任何一步失败整体回滚。相同修订与归档计划重复提交不会重复创建，已撤销的请求也保留去重。

知识与任务页显示来源备忘，链接到归档时的原文修订。修改备忘不覆盖已经产生的知识或日程，旧关联保留其依据；新修订重新进入待整理。普通链接、底部提问和通知导航会检查未保存草稿；识别轮询发现其他窗口保存的新修订时保留本地草稿并提示重新载入。归档检查/提交期间禁用切换及原文编辑。删除目标时保留归档标题及历史，显示目标已删除。

撤销保留原文及共享知识点，只移除本次有效来源关联；未编辑、未参与排程或资料关联的生成待办可以删除。如果待办已被修改、完成或排程，拒绝直接撤销并提示先处理后续变化。备忘进回收站不删除其知识或日程，归档记录依然可查看。

## 开源调研与复用选择

按“直接使用 → 迁移 → 修改 → 自己写”检索后：

- [Memos](https://github.com/usememos/memos)提供随手捕获与轻量整理的产品参考。整体接入会引入独立服务及另一套资料/任务存储，无法直接复用本项目的稳定概念与任务身份，因此不整体迁移。
- [Memos AI 工作流请求 #6442](https://github.com/usememos/memos/issues/6442)讨论非结构文字整理与待办提取；[社区讨论 #5833](https://github.com/orgs/usememos/discussions/5833)涉及 AI 整理及用户控制。这些是参考需求，不把讨论当成已经存在的归档组件或效果保证。
- [思源](https://github.com/siyuan-note/siyuan)的块引用与知识组织提供关系设计参考；本批沿用已有 SQLite 外键、固定修订与回链，不拷贝其应用代码。
- [Chrono](https://github.com/wanasit/chrono)支持自然语言时间解析，但中文为部分支持，不能直接证明“下次课前”等本项目场景有确定解释。本批暂不增加解析依赖：AI 日期只是待审核候选，严格日期校验直接使用已安装的 `@js-temporal/polyfill`；缺少钟点的日期不应由提示词猜出默认截止时间。真实模型仍可能违背指令，所以候选必须人工核对，尚不能自动归档。

直接复用现有 Tiptap/MathLive 输入、Markdown 阅读与别名匹配、LLM 网关与模型配置、知识保存、统一任务、日历冲突及提醒服务。新增代码负责本项目特有的来源修订、审核与事务协调；无新增第三方依赖。

界面沿用现有浅色主题（背景 `#f7f7f5`、白色面板、边界 `#e5e5e0`、文字 `#1f2328`、主色 `#4f46e5`）；左列表用于查找，右侧依次显示原文、识别、归档及历史。复用已有字体与数学输入，不改全站布局。

## 数据与恢复

追加 migration 029：`memos`、不可变 `memo_versions`、`memo_routes`、显式 `memo_targets` 和 `memo_recognitions`。不修改已发布迁移。原文修订记录时间及 IANA 时区；编辑后识别以该修订保存时间解释相对表达，旧识别仍绑定旧修订且不可填入当前草稿。

识别为后台异步请求，有输出上限、两分钟超时、取消和持久状态；请求期间阻止切换数据目录。启动将遗留 running 状态改为可见的中断记录，不未经请求自动重发。失败可手动重新识别；本批没有自动重试队列或完全退出后的后台处理。列表每页 50 条，识别界面显示最近 20 次，原文与归档历史保留。
