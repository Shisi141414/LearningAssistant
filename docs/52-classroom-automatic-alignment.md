# 课堂教材自动定位（2026-11-14）

署名：codex。属于 R6 的本地文本对齐首批，不代表真实课堂准确率或整个项目已经验收。

## 使用方式

开始或继续课堂，选择教材并校准位置，再勾选“自动跟随教材”。默认关闭；设置按课堂笔记保存。只匹配启用后新保存的语段，不批量重写旧课堂。新语段先保存原文，再后台查找教材；语音落段和手动课堂输入使用同一流程。

当前语段至少有三个有效词、文本覆盖足够且明显优于其他候选时，自动更新当前讲授位置。界面可查看定位记录；短句、离题和相近候选显示“位置待校准”，保留上次位置。候选提供原文摘录、匹配词和“按此校准”。“文本匹配度”是当前语段词项的加权覆盖比例，**不是正确概率，也不是经过课堂数据校准的置信度**。

当前提示只显示本场课堂、本次校准之后的判断；旧判断继续保留在定位记录中。相同教材位置新增自动来源时，反向记录也会刷新，不依赖翻页触发。

跳转超过四个来源块需要前后两个语段连续明确匹配同一候选，且间隔小于两分钟；第一次只提示可能跳页或回讲。人工校准更新判断起点、取消旧计算，并保护紧接的一段不自动移到其他位置。停用会取消未完成判断，保留已保存的原文及来源。

浏览历史、搜索或翻阅教材不会修改讲授位置。手动浏览时暂停显示跟随，后台定位仍继续；点击“回到讲授位置”恢复显示跟随。切换所浏览的材料后须明确“校准到这里”，才会改变匹配版本。

## 开源复查与选择

按直接使用 → 迁移 → 修改 → 自写比较：

- 直接使用 [MiniSearch](https://github.com/lucaong/minisearch) 7.2.0 的本地全文检索；[官方选项](https://lucaong.github.io/minisearch/types/MiniSearch.Options.html)支持替换分词。根据[中文支持讨论 #201](https://github.com/lucaong/minisearch/issues/201)核对默认分词限制，本项目使用运行时已有 `Intl.Segmenter`，增加中文长词二字片段及 OCR 汉字间空格归一。不引入另一套数据库、网络检索服务或词典下载。
- [MaViPoLS](https://github.com/tomrance/MaViPoLS) 是学术讲座的多模态语音—幻灯片离线处理方案，依赖视觉模型及嵌入等流程；不能直接接入当前实时、离线优先的转写。保留为语义/多模态后续评估对象，本批没有复制其代码或套用其效果数字。
- 项目特有部分仅负责位置约束、人工校准优先、候选展示、生命周期及不可变来源的衔接。MiniSearch 排名分数没有直接转成“准确率”。

## 数据与运行边界

迁移只追加 v31：按笔记保存控制修订和人工保护标记；每段判断保存会话、原文修订/散列、启用规则修订、初始锚点、状态、候选与最终采用位置。已发布的 v1–v30 不改动。

原始 `segment_material_refs` 继续保留落段时的位置。采用的自动位置是独立派生记录；阅读、教材上下文与反向查找使用同一有效来源规则。自动采用、当前位置、校准事件与新的内部格式来源快照在同一事务中发布；旧来源快照、历史文档和人工整理结构不覆盖。取消或失败仍使用当时的原始来源。

教材整理请求等待对应段落的匹配结束后再读取附近教材；保存转写不等待检索。原文编辑/删除、材料归档、版本状态变化、手动校准、规则变化、课堂结束或退出都会阻止迟到的计算发布。退出时取消匹配和等待，避免等待中的整理在数据库关闭后重新启动。启动时将未完成判断标记为中断，不推测上次课堂仍在继续。

整理请求在开始等待之前固定原文修订，等待结束后再核对，保护等待期间的人工编辑。段落来源批量读取从本笔记出发按主键查找；反向引用分原始/自动分支使用位置索引，避免随材料库增长出现整库交叉扫描。页面合并来源用 ID 映射，避免逐段反复搜索整篇笔记。

单个工作线程缓存当前教材版本的索引，无数据库连接、不发送网络请求。单版本上限 5000 个来源块、400 万字符；单次匹配 10 秒超时，最多排队 8 段。超限或积压转为手动校准，不丢弃原文。定位排队使用原文保存之后的独立事务；排队失败显示提示，原文仍保留。
