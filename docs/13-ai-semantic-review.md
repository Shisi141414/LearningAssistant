# AI 语义拆分建议与审核

> 2026-11-11 · 设计与报告：codex · 方案与首批交付

## 复用和边界

直接复用现有 `streamChat`、供应商密钥管理、模型选择、工作锁、来源覆盖校验和不可变修订；不另写网络客户端或富文本编辑器。复查 [OpenAI Node structured-output helpers](https://github.com/openai/openai-node/blob/master/docs/helpers.md)、[LangChain structured output](https://github.com/langchain-ai/langchain/blob/master/openwiki/structured-output.md)、[Docling 来源追踪](https://github.com/docling-project/docling-graph/blob/main/docs/fundamentals/graph-management/provenance.md)。结构化输出可约束形状，来源是否遗漏/重复、是否覆盖人工修改仍须应用校验。当前兼容多个 OpenAI/Anthropic 接口，不能默认所有供应商支持原生 JSON Schema；先沿用现有客户端并严格解析、拒绝不完整结果，不靠自动重试反复收费。

## 数据与生命周期

- 用户明确选择模型和待整理条目范围，才发送该批文字给所选供应商；不会自动上传整本教材。首批最多 20 条、12000 UTF-16 单元、200 个程序片段；空来源先 OCR，人工确认条目不进入整理范围。
- 程序按换行/短句产生片段 ID，并保留实际来源范围。模型只返回片段 ID 的连续起止、类型、标题及候选内证明/解答关系，不估算字符偏移、不改写原文。
- 所有片段必须按顺序恰好覆盖一次；拒绝未知 ID、越界、缺段、重复、方向错误及无效类型。程序从片段表计算来源范围，再通过完整文档覆盖校验。
- 生成过程独立于当前修订，保存供应商/模型标识、基准修订、范围、状态、错误和已校验候选。生成、失败、取消都不改当前文档。明确超时和取消；应用重启不自动发起新的云请求，中断任务保留提示，可由用户重新生成。
- 用户预览本批类型、标题、正文及证明/解答归属后，“采纳为新修订”才写入当前文档。采纳时核对基准修订没有改变，并再次校验来源、人工结果及关系；旧候选不能覆盖期间的编辑。采纳记录为 AI 方法及人工审核确认，之后同样受确认保护。
- 无模型、无密钥、断网或模型返回坏 JSON 时保留原文和人工结果。候选不接受渲染进程直接提供正文/来源范围；采纳仅传建议 ID。

## 实施前界面计划

沿用材料库的 #f7f7f5 背景、#1f2328 正文、#6b7280 辅助、#e5e5e0 边线和 #4f46e5 操作色。折叠的“AI 整理建议”位于学习文档工具栏下，模型和范围选择在上，任务状态与取消在中，候选预览及“采纳为新修订 / 放弃建议”在下。正文宋体、类型标题黑体、证明/解答楷体，复用已有类型标签和颜色。

界面明确显示“将此批文字发送给所选模型”，并展示实际供应商/模型。建议状态和当前修订状态分开；历史修订只读，不显示生成入口。审核界面沿用已有条目阅读样式，不增加独立的聊天界面或把生成中的文本当作已入库条目。

## 验收计划

片段边界及 UTF-16、来源覆盖、跨来源合并、证明关系、人工保护、坏 JSON/遗漏/重复拒绝、生成不发布、用户采纳才提交、陈旧候选拒绝、取消/断网/超时/重启不自动请求。使用可控的本地模拟供应商完成网络与实际 UI 验收；真实云模型分类质量必须另作样例评估，不能由模拟结果宣称通过。

## 已交付与使用

材料库 → 学习文档 → 展开“AI 整理建议”，选择设置中已配置的模型及连续待整理条目编号，点击“生成本批建议（发送文字）”。候选按已有语义样式显示，可核对原文、类型、标题及证明/解答对象；“采纳为新修订”发布，“放弃建议”只关闭该候选。采纳后可继续人工整理条目。AI 整理历史、供应商/模型及采纳修订均保留；历史文档修订只读。

迁移 v10 仅追加建议记录，不改旧修订与来源。每次最多一个材料 AI 任务，生成可取消；两分钟超时，输出超过 32768 字符即终止。重启后中断任务标记为取消，不自动重新发送教材。所选范围含已确认条目、已有证明/解答关联、空来源或超过容量时拒绝生成，避免越过人工保护边界。

本地模拟供应商通过真实的模型调用链和 Electron 界面验证：生成只保存候选、明确采纳才更新修订、取消与无效结果不发布、人工确认内容不发送/不覆盖、生成后的人工修改使旧建议失效、错误中隐藏密钥，以及跨进程重启恢复。纯逻辑另覆盖跨来源合并、UTF-16 代理对、范围容量、漏段/重复/未知片段、错误关系方向与过长输出。实际桌面已检查候选排版，未向真实云模型发送私密教材。

本批完整 `npm test` 通过（36 项逻辑测试，以及数据库/整理/切块冒烟、Electron 材料/课堂/概念/语义/AI 界面和真实进程重启）；类型检查通过，生产构建包含在集成测试中完成。

超时限制已实现，但本批未用真实慢请求等待两分钟验收；未模拟物理断网，使用请求失败和流取消验证失败保留行为。真实模型分类、标题和证明关系的准确性仍需中文力学教材人工对照，不以流程测试替代质量评估。本批不做 AI 改写 OCR、整本书自动处理、图像/公式识别、章节树或知识点自动合并。
